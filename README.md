# FixItNow Backend API

FixItNow is a RESTful backend API for a home services marketplace. Customers can browse services, create bookings, make payments, and submit reviews. Technicians can manage their profiles, services, and bookings. Admins can manage users, bookings, and service categories.

## Features

- JWT-based authentication
- Role-based authorization
- Customer, Technician, and Admin roles
- Technician profile management
- Service and category management
- Booking management
- Stripe payment integration
- Customer reviews and ratings
- Centralized error handling

## Tech Stack

- Node.js
- Express.js
- TypeScript
- PostgreSQL
- Prisma ORM
- JWT
- bcrypt
- Stripe
